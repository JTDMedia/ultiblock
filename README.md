# ultiblock
UltiBlock is a free open-source anti-adblock service for websites

You can either upload the ultiblock.min.ob.js to your own site and use it like this:
```html
<script type="module" defer src="ultiblock.min.ob.js"></script>
```

Or you use jsdelivr and use it like this:
```html
<script type="module" defer src="https://cdn.jsdelivr.net/gh/JTDMedia/ultiblock@main/ultiblock.min.ob.js"></script>
```
